## Non-negotiable

Before making changes, inspect these image files yourself.

Do not treat them as vague inspiration. The user specifically wants the provided images to be the thing you are matching.

## What the user wants

- The current result is **not close enough**.
- Match the references **materially**, not just in a loose anime-tech vibe.
- Pure procedural / shader-style rendering only.
- No random floating shape soup.
- No decorative card/sprite overlays doing the heavy lifting.
- Multiple display modes are allowed, but each one must clearly resemble one or more of the provided refs.
- Transitions should be smooth and calmer than the current result.
- Slide readability must stay good.
- Performance must stay sane.

## Success criteria

When someone looks at the deck background, they should be able to say it is obviously trying to match these exact attached images.

If it still feels like generic sci-fi UI rather than these refs, it failed.
